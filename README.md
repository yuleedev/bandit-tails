# Bandit Tails

Bandit Tails is a two-player online 3D first-person heist game made in Godot 4. Play as a Raccoon and a Mole competing to steal the most valuable loot while avoiding the guards. The project was created by Arya Gupta, Cade Lam, Mel Kirti, Sophia Chen, and Yulee Oh, with help from Nathan Hu and Qinzhao Li, for Cluster Five (Video Game Design) at UC COSMOS 2025.

## Getting Started/Installation

The game can be played or downloaded here:
https://yuleedev.itch.io/bandit-tails

- **macOS:** Download the macOS build and launch the application.
- **Windows:** Download the Windows build and run the `.exe`.
- **Web:** Play directly in your browser on the itch.io page.

## Controls

- **Mouse:** Look around and navigate menus.
- **WASD:** Move.
- **E:** Hold to pick up loot. Press to pick up keys and open doors.
- **Q:** Use your character's ability.
- **Esc:** Show or hide the mouse cursor.

## How to Play

(The in-game Tutorial screen covers the basics as well!)

### Starting a Game

Bandit Tails needs two players, each on their own device.

1. One player clicks **Host Game** and shares the room code.
2. The other player enters the room code and presses Enter.
3. The host clicks **Start Game**, then **Start** after the character screens.

The host plays as the Raccoon, and the joiner plays as the Mole.

### The Heist

Each round lasts 60 seconds. Search the building for loot, then hold E for about 2 seconds to steal it. Each item has a random value, shown when you get close, and you can only carry 2 items, so choose carefully!

Some doors are locked. Find a key to open one, but remember that each key can only be used once.

### Guards

If a guard sees you, you'll be sent away and frozen for 10 seconds.

### Abilities

- **Raccoon:** Dash quickly in the direction you're moving.
- **Mole:** Burrow underground for 10 seconds, hidden from guards.

### Winning

The player holding the highest total value when time runs out wins the round. After 3 rounds, the player with the most round wins takes the game.
